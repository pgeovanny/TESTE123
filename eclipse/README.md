# ECLIPSE: Herança do Abismo — Alpha

Primeiro experimento de gameplay de navegador do MMORPG anime dark fantasy ECLIPSE.

## Testar
Abra `eclipse/index.html` com um servidor estático ou utilize GitHub Pages apontando para essa pasta. No momento este build é **uma arena offline de validação**, não o backend multiplayer.

## Controles
- WASD: movimento; mouse: seleção de alvo.
- 1–8: barra de habilidades; F: pegar itens; I: inventário.
- Barra de HP, mana, XP, cooldowns, monstros com perseguição, drops e progressão.
