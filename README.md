# ECLIPSE — Herança do Abismo

Protótipo inicial de combate ARPG em navegador (offline).

## Executar
Abrir `index.html` em navegador moderno. No GitHub Pages, publicar a raiz da branch main.

## Controles
WASD ou setas: movimentação. Clique nos monstros: selecionar alvo. Teclas 1–8 ou clique: usar habilidades. Clique direito na habilidade: redefinir tecla. F: coletar drop. I: inventário.

## Estado
Arena experimental com monstros, XP, loot, aprimoramento futuro e oito habilidades. Não é ainda 3D, multiplayer nem versão comercial.
